# Prixel Planner

A browser-based plate planning tool built around the **Prixel Press** piece system. Design layouts, simulate ink colors, track piece counts, and save your work — all in a single HTML file with no install required.

## Launch

**[→ Open Prixel Planner](https://tamag0tcha.github.io/prixel-planner/prixel-planner-v1.html)**

---

## Background

Anyone who's spent time with the Prixel Press system knows the friction: planning layouts by hand, losing count of which pieces you've used, and having no real way to visualize a plate before committing to a print run. A lot of trial and error. A lot of wasted material.

Prixel Planner was built to solve that.

---

## Features

- **Full piece library** — all 34 Prixel Press piece types, organized by category with color-coded filtering
- **16×24 grid** — place, rotate, erase, and move pieces on a true-to-spec setup plate
- **Two color modes** — *Pieces* shows native piece colors; *Ink* simulates how a plate will actually print using your chosen ink color
- **Ink palette** — default inks (black, red, blue, green) plus custom color mixing via a built-in color wheel
- **Multi-plate support** — work across multiple plates in one session, with an overlay mode to see how they composite
- **Mirror mode** — preview your design as it will read in print
- **Selection tool** — marquee-select and move groups of pieces after placement
- **Parts list** — live count of every piece type used on the active plate
- **Save & load** — designs persist in your browser's local storage; create, save, and switch between projects
- **Export PNG** — export the active plate as a PNG

---

## How to Use

1. Download `prixel-planner-v1.html`
2. Open it in any modern browser (Chrome, Firefox, Safari, Edge)
3. Start designing

No server. No install. No account.

---

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `R` | Rotate selected piece 90° |
| `E` | Toggle erase tool |
| `S` | Toggle selection tool |
| `M` | Toggle mirror mode |
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + S` | Save |
| `Esc` | Deselect / clear selection |
| Scroll wheel | Rotate piece under cursor |
| Middle-click + drag | Pan the canvas |

---

## Notes

- Saved designs are stored in your **browser's local storage** — they are not synced across devices or browsers
- The tool works offline; an internet connection is only needed to load the preferred web fonts (system fonts are used as fallback)
- Tested in Chrome, Firefox, and Safari
